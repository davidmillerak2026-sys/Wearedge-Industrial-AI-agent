# Demo Data

This directory contains small, reviewable data fixtures used by tests and PoC flows. It is intentionally lightweight so the repository remains cloneable.

| Path | Purpose |
| --- | --- |
| [`maintenance_kb/`](maintenance_kb/) | Maintenance knowledge snippets and threshold-style evidence for lao-shi-fu workflows. |
| [`iqc_quality_plans/`](iqc_quality_plans/) | Product-specific quality plans, defect rules, and deterministic disposition examples. |
| [`released_sources/`](released_sources/) | Released work-instruction and changeover source fixtures used by source guards. |

## Data Rule

Keep synthetic or sanitized fixtures here. Put customer files, raw factory images, large datasets, model files, and temporary captures outside Git.
