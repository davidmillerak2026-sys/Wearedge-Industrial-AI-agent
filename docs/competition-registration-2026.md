## 最推荐的报名打法

### 1. CAAI 中国“人工智能+”创新创业挑战赛

推荐报名名称：

```text
WearEdge Pro：可穿戴边缘工业多模态 AI Agent 系统
```

推荐赛道：

```text
AI+智能制造
```

推荐组别需要按实际身份确认：

| 真实情况 | 组别建议 |
| --- | --- |
| 未成立公司/个人项目 | 天使组或团队初创类 |
| 已成立公司且年销售额低于 1000 万 | 天使组 |
| 有成熟产品、年销售额或融资额达到 1000 万以上 | 成长组 |

报名理由：

- 赛事明确关注 AI+智能制造、工业智能体、具身智能和核心部件国产化。
- WearEdge 已有端侧本地推理、M400 Android MVP、Jetson gateway、五类工业 Agent、结构化 action card 和审计链路。
- 项目不是单点模型 demo，而是能对接 CMMS/QMS/MES/EHS 的工业场景产品，适合创新创业赛的资源对接逻辑。


### 150 字简介

```text
WearEdge Pro 面向智能制造、航空航天、石油化工等高资产密度场景，构建“AR/M400 视觉采集 + 随身 Jetson 边缘算力 + 本地多模态模型 + 工业 Agent 工作流”的可穿戴智能系统。项目已跑通 Jetson Orin Nano 8GB 本地 Gemma 4 E2B 多模态推理、FastAPI 网关、M400 Android 客户端 MVP、五类工业 Agent 和结构化 action card，可在不上传生产图像的前提下完成预测性维护、IQC 质检、换型指导、作业指导和 EHS 风险识别。
```

### 500 字项目概述

```text
WearEdge Pro 是一套面向工业前线的可穿戴边缘多模态 AI Agent 系统。工业现场普遍存在三类矛盾：生产图像、工艺参数和维修日志不能轻易上传云端；质检、排障和安全预警要求低延迟；一线工人双手被作业占用，难以通过传统电脑或手机交互。WearEdge Pro 采用“感知与算力分离”的架构，用 M400/AR 眼镜采集第一视角图像，用随身 Jetson 边缘节点承载本地多模态模型、工业 RAG、确定性规则和 Agent 编排，让工人以免脱手方式获得可追溯的专家支持。

项目当前已完成可运行 PoC：Jetson Orin Nano 8GB 上部署 Gemma 4 E2B GGUF 与 mmproj vision projector，通过 llama.cpp CUDA 后端和 FastAPI gateway 提供本地多模态推理；M400 Android Camera2 MVP 已可编译，具备网关预检、拍照上传和审计回查入口；后端实现 maintenance、iqc、changeover、wi、hazard 五类工业 Agent 路由，并通过结构化输出契约、证据优先 RAG、阈值判断和 action card 把模型输出转化为可接入 CMMS、QMS、MES、EHS 的工业事件。

WearEdge Pro 的核心创新不在于简单调用大模型识图，而在于把概率模型限制在可审计、可测试、可落地的工业责任边界内。系统只让模型解释证据，不让模型越权决定停机、放行或复机；动作通道、责任人、优先级和集成目标由 deterministic action map 输出。项目已完成 25/25 golden scenario 验证和真实 Jetson gateway POC，证明同一套 runtime 可支撑预测性维护、在线质检、换型指导、作业指导和安全巡检。
```

### 核心技术与竞争优势

```text
1. 端侧本地推理：生产图像、设备知识库和推理日志留在工厂边缘节点，适合数据安全要求高的制造现场。
2. 可穿戴一线入口：M400/AR 第一视角采集与骨传导音频规划让系统适合免脱手、强噪音、高风险工位。
3. 工业 Agent 工作流：同一 runtime 支撑 maintenance、iqc、changeover、wi、hazard 五类场景，不是一次性 demo。
4. 结构化输出契约：模型结果被硬化为 scene/risk/action 或各 Agent 专属字段，下游 CMMS/QMS/MES/EHS 可直接消费。
5. 证据优先与责任边界：RAG、阈值判断、低证据拦截、人机确认和 deterministic action map 防止模型幻觉与越权动作。
6. 可复验工程证据：Jetson gateway、M400 Android MVP、systemd 自启动、审计日志、smoke test、25/25 golden scenario 均已有项目记录。
```

### 1 分钟路演结构

```text
第一句：WearEdge Pro 做的是工业现场的可穿戴边缘 AI Agent，不是云端识图 demo。

痛点：工厂图像和知识库不能随便出厂；维修、质检、安全必须低延迟；工人双手被占用，传统交互方式不适合现场。

方案：M400/AR 眼镜采集第一视角，Jetson 随身边缘节点本地运行多模态模型与工业 Agent，输出可审计 action card。

创新：我们把模型限制在证据解释层，RAG、阈值、动作路由和人机确认由确定性工作流执行，解决工业 AI 的幻觉、责任边界和系统集成问题。

进展：Jetson 本地推理、FastAPI 网关、M400 Android MVP、五类 Agent、25/25 golden scenario 和真实网关 POC 已完成。

落地：先切入预测性维护、在线 IQC、换型指导和 EHS 近失事件记录，再对接 CMMS/QMS/MES/EHS，帮助工厂减少停机、返工、培训和安全风险。
```
