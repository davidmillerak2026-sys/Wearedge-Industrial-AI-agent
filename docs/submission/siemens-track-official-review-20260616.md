## 参赛定位

Wearedge 当前按 **企业组** 参加 **场景赛赛题一：西门子（中国）有限公司题目**。项目口径应始终围绕：

> 基于智能制造实际场景的质量管控智能体、能源管理智能体、设备运维智能体、生产制造-柔性生产智能体的协同决策；基于工易魔方开发的智能体。

这意味着我们的提交材料不能写成通用 AI demo、单一 Chatbot 或纯本地边缘推理项目，而要写成：

```text
端侧工业智能体运行时 + 西门子 Xcelerator / 工易魔方工作流编排 + 人机协同审批 + 数据回写的联合解决方案。
```

## 不能遗漏的合规边界

- 企业组要求中国境内注册、符合中小微企业标准；最终需以负责人提供的营业执照和企业信息为准。
- 官方页面要求参赛团队、企业情况、知识产权承诺等材料；这些不能由技术文档替代。
- 同一人员不得以多个团队重复参赛；最终提交前要由负责人确认。
- 项目材料不得将离线模拟数据写成真实客户生产数据。
- Xcelerator 服务当前如保持草稿/租户内状态，就不能写成“已公开上架”。
- WFC 临时 tunnel、localhost、本地 smoke test 只能写成 PoC 或预验证，不能写成稳定平台复现地址。
