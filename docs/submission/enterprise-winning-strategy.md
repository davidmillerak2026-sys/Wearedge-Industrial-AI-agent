# 企业组夺冠策略

更新日期：2026-06-09

## 夺冠定位

Wearedge 以企业组参赛，主打“企业可交付 + 端侧可部署 + 平台可编排 + 产线可落地”。项目不写成个人 demo，也不写成云端 Chatbot，而是写成可与 Siemens Xcelerator / 工易魔方共创的工业智能体联合解决方案。

## 评分反推

| 评分维度 | 夺冠打法 | 证据 |
| --- | --- | --- |
| 创新性 30% | 端侧产线级协同智能体，不是单点问答 | Edge Runtime、M400/Jetson、五智能体联合、HumanApprovalGate |
| 技术水平 30% | API、资源块、离线指标、测试全可复验 | `/v1/edge/runtime-profile`、WFC block、pytest、eval、OpenAPI |
| 应用前景 20% | 面向多 SKU 制造，ROI 可量化 | 商业计划书、ROI 表、目标客户、共创路线 |
| 团队能力 10% | 企业主体和交付分工可信 | 团队模板、IP 合规、企业信息待填 |
| 可行性 10% | 平台和本地双路径演示 | Demo 脚本、截图清单、A/B 路应急方案 |

## 必须坚持的表达

- Xcelerator / 工易魔方负责平台编排，Wearedge 负责现场边缘智能。
- 模型解释证据，确定性守卫决定动作边界。
- 高风险动作只进入人工确认，不直接写 PLC、停线或质量放行。
- 当前指标是离线/仿真验证，真实平台日志会在 PoC 阶段补齐。

## 截止前优先级

1. 完成 WFC 资源块原型包和端侧 runtime profile 截图。
2. 录制三段式 demo：端侧运行、协同决策、平台闭环。
3. 把企业主体、团队、IP 和无不良记录材料补齐。
4. 7月8日前正式提交，7月9-10日只做异常缓冲。
