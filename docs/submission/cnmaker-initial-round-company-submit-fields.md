项目简介，页面限制不多于 2000 字：

```text
Wearedge端侧工业智能体协同决策系统面向多SKU离散制造产线中设备健康、质量风险、能源窗口和换型调度相互影响但难以协同的问题，计划基于西门子Xcelerator智能体开发平台和工易魔方开发平台，共创一套可执行、可审批、可回写的工业智能体联合解决方案。

系统的核心不是工业问答机器人，而是可部署在Jetson、IPC、本地工控机或边缘服务器上的Wearedge Edge Agent Runtime。端侧智能体贴近产线数据运行，接收MES、设备信号、质量数据、能源数据、维护记录、released checklist和Workflow Canvas上下文，再通过工易魔方资源块、Python Function Block、全局数据表、Dashboard和HumanApprovalGate，把AI分析转化为结构化工业决策和可审计工作流。

当前方案覆盖设备运维智能体、质量管控智能体、能源管理智能体、柔性生产智能体和Workflow Canvas智能体。设备运维智能体负责预测性维护、预警和根因候选；质量管控智能体负责缺陷隔离、扩检和质量工程师确认；能源管理智能体负责能耗预测和节能窗口建议；柔性生产智能体负责换型约束、排产建议和首件验证；Workflow Canvas智能体负责平台资源块、功能块、数据表、Dashboard和人工确认编排。

技术路线采用“模型解释 + KPI矩阵 + 确定性守卫 + 人工确认”的安全边界。模型用于理解图片、日志、SOP和现场上下文，生成可读解释和建议；最终方向选择、优先级、指标达标、残余风险和审批要求由确定性决策器生成。高风险动作进入HumanApprovalGate，不让模型文本直接写PLC、质量放行或能源策略。

项目已完成算法原型代码、Workflow Canvas decision API、工易魔方接入包、Xcelerator API草稿、离线评估数据集和评估脚本。离线/仿真验证中，设备运维维护F1最低87.0%，满足故障预测准确率或预警判定质量不低于85%的初赛要求；柔性生产调度效率提升最低21.0%，满足调度优化效率提升不低于20%的要求。Jetson端侧FastAPI决策路径完成300轮、4500个HTTP样本采证，p95/max延迟为6/33ms，证明端侧部署具备低延迟潜力。上述数据为离线/仿真和平台PoC证据，不表述为真实客户量产数据。

目标客户包括汽车零部件、电子装配、包装、食品、医药和多品种小批量离散制造企业，尤其适合已使用或计划使用西门子Xcelerator、工易魔方、MES、QMS、EMS、CMMS的工厂。商业模式包括联合PoC服务、工易魔方场景模板授权、边缘Agent Runtime部署集成和持续运营服务。项目希望与西门子专家团队共创可复用的产线级工业智能体模板，帮助客户减少非计划停机、降低缺陷和返工、优化能耗、缩短换型协调时间，并沉淀一线专家经验。
```
